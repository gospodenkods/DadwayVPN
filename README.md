# Dadway VPN v7.5.0 Debug

Android-клиент Dadway VPN на базе libXray с двумя профилями подписки и автоматическим резервированием.

## Возможности

- профили «Основной сервер» и «Резервный сервер»;
- отдельный кэш для каждой подписки;
- автоматическое переключение на резервную подписку, когда основная недоступна;
- VLESS/VMess/Trojan/Shadowsocks через конвертер libXray;
- исправление параметров REALITY и XHTTP после конвертации;
- локальный SOCKS5, TUN, метрики, проверка IP, ping, скорости и экспорт журнала;
- фирменный неоновый интерфейс Dadway VPN;
- автоматическая сборка APK через GitHub Actions.

## Версия

- `versionCode`: 90
- `versionName`: 7.5.0 Debug

## Сборка

При push в ветку `main` GitHub Actions собирает debug APK и публикует артефакт `DadwayVPN-v7.5.0 Debug-apk`.

Инструкция по загрузке находится в `UPLOAD_TO_GITHUB.md`.
