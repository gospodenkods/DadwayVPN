# Dadway VPN v7.3.3

Android-клиент Dadway VPN с интерфейсом, переработанным по утверждённому макету.

## Интерфейс

- тёмно-синий неоновый фон;
- верхний логотип без белых углов, с тонким голубым обрамлением;
- кликабельные панели DADWAY.RU и Telegram @GDS_TECHNICAL;
- крупная панель состояния VPN;
- фирменная кнопка подключения/отключения;
- карточки сервера, внешнего IP, ping, сессии и скорости;
- вспомогательные кнопки проверки IP, теста скорости, логов, настроек и обновления подписки.

## Версия

- versionCode: 73
- versionName: 7.3.3

## Сборка

При push в ветку `main` GitHub Actions автоматически собирает debug APK и публикует артефакт `DadwayVPN-v7.3.3-apk`.

Инструкция: `UPLOAD_TO_GITHUB.md`.

## Профили подключения

Перед подключением в приложении доступен выпадающий список:

- **Основной сервер** — загружает актуальную конфигурацию с сервера подписки;
- **Резервный сервер** — использует встроенную конфигурацию подключения к резервному узлу.

Последний выбранный профиль сохраняется на устройстве. Во время активного подключения список блокируется, чтобы конфигурация не менялась до отключения VPN.
