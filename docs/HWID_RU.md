# HWID подписок — Dadway VPN 8.6.7

Каждый сетевой GET-запрос обновления активной подписки содержит заголовок `X-HWID` (HTTP-имена заголовков регистронезависимы). Значение — 64 шестнадцатеричных символа SHA-256 от `DadwayVPN-HWID-v1:<applicationId>:<seed>`. Версия приложения и адрес подписки не входят в идентификатор. Доступ к сохранённому кэшу без сетевого запроса ничего не отправляет.

Основной seed — `Settings.Secure.ANDROID_ID`. Идентификатор сохраняется при обычном обновлении с тем же ключом подписи на том же устройстве и в том же Android-профиле. После сброса устройства, смены профиля или ключа подписи он может измениться. Google Play и APK с разными ключами подписи могут иметь разные Android ID. При недоступном Android ID используется локальный UUID из `noBackupFilesDir`, который сохраняется при обновлении, но не переносится резервной копией на другое устройство.

IMEI, серийный номер, MAC, модель устройства и исходный Android ID не передаются. HWID не помещается в URL, журналы или экспорт лога. HTTPS обязателен. При редиректе идентификатор отправляется только тому же origin (схема, хост, порт), что у сохранённой подписки; другие хосты получают запрос без HWID. Переход на HTTP и более пяти редиректов отклоняются.

## Подключение серверной обработки

На сервере прочитайте `X-HWID` из HTTP-заголовков запросов подписки; если используется прокси, сохраните этот заголовок при передаче запроса обработчику. В связанном локальном проекте DadwaySubs обработчик HWID не обнаружен. Этот релиз добавляет отправку клиентом, но не реализует серверное ограничение количества устройств. Для шлюза на другой origin явно согласуйте протокол передачи идентификатора, прежде чем разрешать его пересылку.

Управление подписками содержит пояснение о передаче HWID. Перед публикацией версии сведения о сборе идентификаторов должны соответствовать этой передаче в политике конфиденциальности и разделе безопасности данных Google Play. Хешированный стабильный идентификатор всё ещё является идентификатором устройства/приложения.

Проверки CI: стабильность и формат HWID; заголовок при обновлении; редиректы внутри origin, на другой хост и порт; запрет HTTP; сохранение отказа 403. Это проверки клиентского протокола; фактическое принятие HWID конкретным сервером нужно проверять по серверному обработчику.
