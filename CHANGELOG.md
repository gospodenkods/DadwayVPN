# Dadway VPN v7.3.3

- Исправлена ошибка Xray `empty "serverNames"` для REALITY.
- Поля `serverName` и `serverNames` синхронизируются перед запуском ядра.
- Поиск прокси-outbound больше не зависит от его позиции в массиве.

# Dadway VPN v7.3.3

- Исправлена передача исходной VLESS-ссылки в XrayConfigBuilder.
- Параметр REALITY `sni` теперь восстанавливается в `realitySettings.serverName`.
- Добавлена явная ошибка при отсутствии SNI вместо неинформативного `empty serverNames`.
- Сохранены отдельные подписки и кэши основного и резервного серверов.

# Changelog

## 7.3.1

- Исправлена ручная загрузка подписки в `MainActivity`.
- В `SubscriptionClient.fetch()` теперь передаются URL и ключ кэша выбранного профиля.
- Устранена ошибка компиляции `No value passed for parameter subscriptionUrl/cacheKey`.
- Основная и резервная подписки по-прежнему используют раздельный кэш.

# 7.3.0

- Резервный сервер переведён на подписку `https://zpp.div3.ru:2096/sub/m315s5c3qc51hkoj`.
- Для основного и резервного серверов используются независимые кэши подписок.
- Сохранено автоматическое переключение с основного сервера на резервный.
- Удалена встроенная статическая VLESS-конфигурация резервного сервера.

# 7.3.0

- Исправлено формирование REALITY-конфигурации резервного сервера: SNI `max.ru` принудительно переносится в `serverName` и `serverNames`.
- Добавлена нормализация параметров REALITY: fingerprint, publicKey, shortId, spiderX и post-quantum verify key.
- Добавлена нормализация XHTTP: network, path, mode и host.
- Добавлена проверка обязательного SNI до запуска Xray.
- Основная подписка продолжает использовать последний успешный кэш при временной ошибке сети.
- Если основной сервер недоступен и кэша нет, приложение автоматически запускает резервный сервер.
- Улучшено журналирование автоматического переключения.
