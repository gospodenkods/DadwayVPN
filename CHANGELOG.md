# Changelog

## 8.5.9
- Включена явная перепаковка классов R8 через `-repackageclasses`.
- Сохранены JNI-имена `libXray` с отдельным keep-правилом.
- CI проверяет итоговую объединённую конфигурацию R8 и отклоняет сборку при отключённой перепаковке.
- Включён обратно совместимый edge-to-edge через `enableEdgeToEdge()` для Android 15/16 и более ранних версий.
- Добавлена обработка системных панелей, экранных вырезов, оконного режима и экранной клавиатуры через `WindowInsetsCompat`.
- Удалены отключённые в Android 15 API и атрибуты цветов системных панелей; Material Components обновлён до 1.14.0.
- Release CI запускает Android Lint и блокирует возврат к неподдерживаемым параметрам edge-to-edge.
- Остановка foreground service совместима с API 23; исправлены AppCompat-атрибуты tint, обнаруженные Android Lint.
- Версия обновлена до `8.5.9` (`versionCode` 859).

## 8.5.8
- Сборочная цепочка обновлена до AGP 9.0.1 и Gradle 9.1.0.
- Выполнена миграция на встроенную поддержку Kotlin в AGP 9 без устаревшего `org.jetbrains.kotlin.android`.
- Google Play-пакет сохранён как `ru.dadway.dadwayvpn`; `versionCode` увеличен до 858.
- Добавлена подписанная Google Play-сборка `DadwayVPN-8.5.8.aab` только для ARM-архитектур.

## 8.5.7
- Добавлена подписанная Google Play-сборка `DadwayVPN-8.5.7.aab`.
- Google Play-конфигурация обновлена до `applicationId ru.dadway.dadwayvpn`, `versionCode 857`, `targetSdk 36` и `compileSdk 36`.
- Сборочная цепочка обновлена до AGP 8.10.1 и Gradle 8.11.1 с проверкой подписи и ARM-библиотек внутри AAB.
- Поле «Пинг» теперь показывает медианную TCP-задержку до фактического `host:port` выбранного VPN-сервера.
- Удалено ошибочное использование длительности HTTPS-запроса к сервису внешнего IP в качестве пинга.
- Перед подключением выполняются три измерения узла; проверки внешнего IP и скорости больше не перезаписывают это значение.
- Для Google Play версия 8.5.7 использует `versionCode` 857.

## 8.5.6
- Добавлена одноразовая миграция, полностью очищающая сохранённый список подписок после обновления с предыдущей версии.
- Вместе со старыми источниками удаляются их локальные кэши и сохранённый выбор сервера.
- После завершения миграции новые пользовательские подписки сохраняются при последующих запусках и обновлениях.
- Сохранены `applicationId` и release-подпись; `versionCode` увеличен до 143 для установки поверх 8.5.5.
- Версия интерфейса и APK обновлена до `8.5.6`.

## 8.5.5
- Подготовлен production-релиз без суффикса `test` и без метки `test_realised` в интерфейсе.
- На чистой установке список подписок пуст; приложение больше не привязано к встроенному URL.
- При обновлении удаляются только ранее встроенные источники, а самостоятельно добавленные подписки сохраняются.
- Добавлена понятная подсказка для первого добавления подписки и русскоязычная иллюстрированная инструкция.
- Для XHTTP + REALITY fingerprint `chrome` автоматически заменяется на проверенный совместимый профиль `safari`.
- При временной ошибке DNS/сети подключение использует сохранённую подписку; ответы 401/403/404/410 по-прежнему немедленно блокируют доступ.
- Добавлен регрессионный тест нормализации REALITY fingerprint.
- Версия обновлена до `8.5.5` (`versionCode` 142).

## 8.5.4
- Исправлен запуск TUN на Android 16: в конфигурацию Xray добавлено явное имя интерфейса `xray0`.
- Исключён запрещённый Android netlink-запрос `net.Interfaces()`, появившийся при пустом имени TUN в Xray-core 26.7.28.
- Длинные внутренние ошибки Xray больше не выводятся целиком на главном экране; технические подробности сохраняются в журнале.
- Добавлен регрессионный тест итоговой TUN-конфигурации и `xray.tun.fd`.
- Версия обновлена до `8.5.4-test-android16-tun` (`versionCode` 141).

## 8.5.3
- libXray обновлён до официального релиза `v26.7.28`.
- DNS-резолвер libXray настраивается через `LibXray.setDNS` и сбрасывается через `resetDNS` только после остановки Xray.
- Перед проверкой подключения приложение ждёт доступности `127.0.0.1:10808` до 10 секунд.
- Сетевая проверка выполняется до трёх раз с задержкой между попытками.
- Жизненный цикл Xray сериализован: параллельный запуск второго экземпляра исключён.
- Версия обновлена до `8.5.3-test-libxray-dns` (`versionCode` 140).

## 8.5.2
- Официальная подписка загружается только через итоговый генератор `devel.dadway.ru/sub/promo`.
- Удалены автоматически добавленные прямой upstream `mikrot.icu` и устаревший `/sub/zpp` вместе с их кэшами.
- Пользовательские дополнительные подписки и переключатели активности сохранены.
- Полностью запрещён незашифрованный HTTP-трафик подписок.
- Версия обновлена до `8.5.2-test-final-subscription` (`versionCode` 139).

## 8.4.7
- Критические ответы подписки `401/403/404/410` больше не маскируются локальным кэшем.
- При отключении или истечении подписки сохранённые серверы и выбранный сервер удаляются.
- Перед подключением выполняется обязательная проверка подписки без резервного кэша.
- Активное VPN-соединение проверяет подписку каждую минуту и отключается при отзыве доступа.
- При временной ошибке сети сохранённый список явно помечается как кэшированный.

## 8.2.0
- Полностью обновлён главный экран по утверждённому тёмному жёлто-красному дизайну.
- Серверы Россия, USA и Netherlands расположены в одной строке по три карточки.
- Добавлены новые флаги, логотип-щит, круглые состояния подключения, карточки метрик и нижняя панель действий.
- Сохранены подписки и логика VPN версии 8.1.0.

# Changelog

## 7.6.0

- Объединены исправления версий 7.3.1–7.3.3.
- Исправлена клиентская REALITY-конфигурация: используется `realitySettings.serverName`; серверное поле `serverNames` удаляется из outbound.

- Добавлена проверка обязательных параметров REALITY до запуска Xray.
- Сохранены отдельные подписки и кэши основного и резервного серверов.
- Сохранено автоматическое переключение на резервный сервер при ошибке загрузки основной подписки.
- Улучшено журналирование: профиль, протокол и адрес сервера записываются без вывода ключей и UUID.
- Обновлены GitHub Actions, имена APK и артефактов.
