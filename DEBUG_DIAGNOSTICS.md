# Dadway VPN 7.5 Debug

Эта сборка предназначена для диагностики ошибки REALITY `empty "serverNames"`.

При каждом подключении она сохраняет во внутреннем каталоге приложения:

- `dadway-xray-base-raw.json` — JSON сразу после libXray-конвертера;
- `dadway-xray-final-raw.json` — JSON непосредственно перед `runXrayFromJson`;
- две версии этих файлов с удалёнными секретами.

Кнопка **Сохранить лог** экспортирует единый TXT-файл с журналом и обеими конфигурациями, в которых удалены UUID, пароли, publicKey, shortId и другие секреты.

Для анализа после неудачного подключения сохраните лог и передайте именно экспортированный TXT-файл.
